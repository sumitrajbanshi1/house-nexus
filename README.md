## ✨ Features

* **Interactive Landing Page (`index.html`):** Features a touch-sensitive star-constellation canvas background, typewriter introduction effect, and 3D glassmorphism tilt card.
* **Resident Dashboard (`portal.html`):** 
  * 📶 **Wi-Fi Access:** One-click network credentials display.
  * 🗑️ **Waste Management:** Clear bin collection schedules (General, Recycling, Organics).
  * 🧹 **House Rules:** Shared cleaning protocols and quiet hour guidelines.
  * 📄 **Document Downloads:** Direct links to Tenancy Agreements and Checklists.
* **Fully Responsive:** Optimized for desktop, tablet, and mobile views.
